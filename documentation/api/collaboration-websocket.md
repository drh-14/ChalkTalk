# Collaboration WebSocket protocol

Answer and followup WebSocket editing is **not available**. The earlier Hocuspocus design was replaced with independent local drafts and explicit, version-checked REST saves. No answer or followup connection-ticket endpoint exists. See the [answers and followups API reference](answers.md).

Post- or subchannel-scoped temporary collaboration sessions remain future work. Their proposed routes in the OpenAPI reference are not implemented and do not authorize a connection to answer or followup bodies.
