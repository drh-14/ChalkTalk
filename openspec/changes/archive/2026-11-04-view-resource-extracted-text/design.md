# Decisions

Use the existing resource ownership/visibility rules. GET /api/v1/courses/{courseId}/resources/{resourceId}/text returns {data:{fileId,status,text,truncated}} with private, no-store caching. Status is pending/ready/failed/unsupported; text is null unless ready and truncated is false unless ready. Pending rows may be absent. Read membership, active revision and text in one repeatable-read, read-only transaction. Link, deleted, hidden, wrong-course and inaccessible resources return 404, missing session 401 and unavailable service 503. Archived-course members retain read access. No failure codes or old file texts are exposed.

The inline viewer fetches only when opened and again on Refresh text/Try again. Close aborts requests; resource/version remount discards stale content. Render full stored text with React text nodes, including literal HTML. Show truncation and empty-text states. Include the action for uploads in catalog and search results for all authorized readers; no action for links. Preserve card drafts and original download.

Keep View extracted text, Edit and Remove in a compact wrapping action row, with short visible Edit/Remove labels and resource-specific accessible names. Expanded text occupies the full main-column width below the actions. Wrap card contents in a flexible main column with a right-hand pair of 40px arrow buttons, labelled Move resource up/down, with resource name available in a labelled group. Preserve existing order API, disabled boundaries/pagination/pending rules and instructor-only visibility. Compact section controls are out of scope.

# OCR correction from demo feedback

The supplied 18-page PDF has 250 selectable non-whitespace characters on page 1 and 91 on every other page, all header/footer material. Each article page is a large CCITT stencil. The old 20-character threshold skips OCR entirely. Inspect pdfimages -list only when a page has 20–499 characters; parse image/stencil physical area using width, height and x/y PPI, compare the largest image with the page crop area at a 50% threshold. Ignore mask-only entries and malformed sizes; fail rather than silently complete when metadata is unavailable/incomplete. Keep the existing OCR loop and budgets. pdfimages is already installed by poppler-utils; include it in the worker tool probe. Reprocess only the reported current upload after restarting worker. User requests demo first: run just the essential regression for this defect, not the broad suites or gate.
