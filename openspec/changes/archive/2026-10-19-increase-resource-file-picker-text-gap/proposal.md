## Why
The user requested about 10% more space between the Resources native Choose File button and its adjacent filename or No file chosen text.

## What Changes
Set only the scoped native selector margin-inline-end to 4.4px, 10% above the measured Chromium baseline of 4px.

### New Capabilities
### Modified Capabilities
- `course-resource-links`: Slightly increase native chooser-to-filename spacing.

## Impact
One Resources CSS declaration, focused desktop/mobile browser coverage and evidence; no other control, padding, color, label, layout or backend changes.
